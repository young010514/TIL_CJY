# TIL_CJY

SSAFY에서 학습한 내용을 기록하고 정리하는 TIL 저장소입니다.
Python 문법과 알고리즘 문제 풀이부터 DB, Django, Django REST Framework, JavaScript, Vue.js, 프로젝트 실습까지 학습 과정에서 작성한 코드와 정리 내용을 보관합니다.

이 저장소는 단순히 수업 자료를 모아두는 공간이 아니라, 배운 내용을 직접 실습하고 프로젝트에 적용하면서 개발자로 성장하는 과정을 기록하기 위한 공간입니다.

---

## 학습 목표

* Python 기본 문법과 자료구조 활용 능력 향상
* 알고리즘 문제 풀이를 통한 문제 해결력 강화
* DB, SQL, ORM에 대한 이해
* Django 기반 웹 애플리케이션 개발 흐름 학습
* Django REST Framework를 활용한 API 설계 및 구현 경험 축적
* JavaScript와 Vue.js를 활용한 프론트엔드 동작 이해
* 주차별 프로젝트를 통한 실전 구현 경험 정리

## Main Topics

### Python & Algorithm

Python 기본 문법을 바탕으로 자료구조와 알고리즘 문제 풀이를 정리했습니다.

학습 내용은 다음과 같습니다.

* 리스트, 문자열, 스택, 큐, 트리 등 기본 자료구조
* 정렬 알고리즘
* Union-Find
* SWEA, Baekjoon, Jungol, CodeTree 문제 풀이
* 입력 처리 및 문제 풀이 패턴 정리
* 반복 풀이를 통한 구현력 향상

알고리즘 학습은 단순히 정답 코드를 작성하는 것보다, 문제를 읽고 조건을 구조화한 뒤 풀이 흐름을 코드로 옮기는 연습에 중점을 두었습니다.

---

### Database

DB 학습 폴더에는 수업 중 실습한 데이터베이스 관련 내용을 정리했습니다.

주요 학습 방향은 다음과 같습니다.

* 관계형 데이터베이스의 기본 개념 이해
* 테이블 구조와 데이터 관계 이해
* SQL 기본 문법 실습
* 데이터 조회, 조건 처리, 정렬, 집계 등 실습
* Django ORM 학습을 위한 기반 지식 정리

DB 학습을 통해 웹 서비스에서 데이터가 어떤 구조로 저장되고 조회되는지 이해하는 데 집중했습니다.

---

### Django

Django 폴더에서는 웹 애플리케이션 개발에 필요한 기본 구조와 백엔드 기능 구현 과정을 학습했습니다.

주요 학습 내용은 다음과 같습니다.

* Django 프로젝트 및 앱 구조 이해
* URL, View, Template 흐름 학습
* Model 설계 및 Migration
* ORM을 활용한 데이터 생성, 조회, 수정, 삭제
* 사용자 인증 기능 학습
* 프로젝트 단위 기능 구현 연습

Django 학습을 통해 단순한 페이지 구현을 넘어, 데이터베이스와 연결된 웹 서비스의 전체 흐름을 이해하는 데 집중했습니다.

---

### Django REST Framework & API

API 폴더에서는 Django REST Framework를 활용한 API 구현 과정을 학습했습니다.

주요 학습 내용은 다음과 같습니다.

* JSON 응답 구조 이해
* Serializer를 활용한 데이터 변환
* REST API 기본 구조 학습
* 요청과 응답 흐름 이해
* 백엔드와 프론트엔드 간 데이터 전달 방식 학습

API 학습을 통해 서버가 데이터를 어떻게 제공하고, 클라이언트가 이를 어떻게 활용하는지 이해했습니다.

---

### JavaScript

JavaScript 폴더에는 프론트엔드 동작 구현을 위한 기본 문법과 실습 내용을 정리했습니다.

주요 학습 방향은 다음과 같습니다.

* JavaScript 기본 문법
* 조건문, 반복문, 함수
* 배열과 객체
* DOM 조작
* 이벤트 처리
* 비동기 동작 이해

JavaScript 학습을 통해 정적인 웹 페이지에 사용자와 상호작용할 수 있는 동작을 추가하는 방법을 익혔습니다.

---

### Vue.js

Vue.js 폴더에는 Vue 기반 프론트엔드 학습 내용을 정리했습니다.

주요 학습 방향은 다음과 같습니다.

* Vue 프로젝트 구조 이해
* 컴포넌트 기반 개발 방식 학습
* 데이터 바인딩
* 이벤트 처리
* 프론트엔드 상태 관리 흐름 이해

Vue.js 학습을 통해 화면을 컴포넌트 단위로 나누고, 데이터 변화에 따라 화면이 갱신되는 구조를 이해했습니다.

### PJT

PJT 폴더에는 주차별 프로젝트 실습 내용을 정리했습니다.

프로젝트를 통해 단순 개념 학습에서 끝나지 않고, 실제 요구사항을 바탕으로 기능을 설계하고 구현하는 경험을 쌓았습니다.

주요 학습 방향은 다음과 같습니다.

* 요구사항 분석
* 모델 및 데이터 구조 설계
* 기능 단위 구현
* 에러 해결 과정 기록
* 프로젝트 회고 및 개선점 정리

각 프로젝트는 배운 개념을 실제 서비스 형태로 적용해보는 과정으로 활용했습니다.

## 학습 방식

이 저장소는 다음과 같은 방식으로 관리하고 있습니다.

1. 수업 중 배운 개념을 코드로 실습합니다.
2. 실습 과정에서 발생한 오류와 해결 과정을 기록합니다.
3. 알고리즘 문제는 풀이 코드와 함께 반복 학습합니다.
4. 프로젝트에서는 기능 구현 흐름과 개선점을 함께 정리합니다.
5. 학습한 내용을 이후 프로젝트에 적용할 수 있도록 구조화합니다.

## Commit Convention

현재는 학습 기록 중심으로 커밋하고 있으며, 앞으로는 아래와 같은 기준으로 커밋 메시지를 정리할 예정입니다.

```bash
feat: 새로운 기능 또는 실습 코드 추가
fix: 오류 수정
docs: 문서 또는 README 수정
study: 학습 내용 정리
refactor: 코드 구조 개선
```
