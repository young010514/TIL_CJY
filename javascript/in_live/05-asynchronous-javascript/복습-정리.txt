이벤트 : 무언가 일어났다는 신호  => 웹 상에서 어떻게 구현할까?

1. 요소를 가져오기 (querlSelector)
2. 이벤트 핸들러 틀 작성 (콜백함수, 실제로 이벤트가 발생했을 때 동작할 함수)
3. addEventListener 로 요소와 이벤트 핸들러를 연결
4. 이벤트 핸들러 내부 작성하기

버블링 : 이벤트가 상위 요소로 전달되는 것
- event : 콜백함수에 첫 번째 파라미터로 전달됨 (이벤트에 대한 정보가 담겨짐)
- event.target: 이벤트가 발생한 원본 지점
- event.currentTaget: 실제로 지금 이벤트가 발생하고 있는 지점
캡처링 : 하위 요소로 전달 ( 사용 X , 중간에 권한 탈취하던가)
