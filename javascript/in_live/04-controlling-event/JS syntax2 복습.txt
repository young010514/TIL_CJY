    - 일반함수: 전역객체

- 콜백함수
    - 다른 함수로부터 호출되는 함수
- Array Method
    - forEach
        - arr.forEach(function(item, index, array){
        // item: 현재 접근하고 있는 인자
        // index: 현재 접근하고 있는 인자의 인덱스
        // array: 접근하고 있는 배열 전체
        })
        - 단순 순회용, 반환값도 없다.
    - map
        - arr.map(function(item, index, array){
        return (데이터)
        })
        - 원본 배열을 변경하지 않고, 새로운 배열을 반환
        - 원본과 크기가 같은 배열이 생성된다.
    - filter
        - arr.filter(function(item, index, array){
        return true or false
        })
        - return 값이 false인 애들을 제외하고, true인 애들만 모아서 새로운 배열을 만든다.
        - 원본과 크기가 같거나 작은 애들이 만들어지겠죠
    - reduce
        - arr.reduce(function(acc, cur, index, array){
        // acc: 이전까지 누적된 값
        // cur: 현재 쳐다보고 있는 값
        }, 초기값)
        - 배열을 완전히 다른 형태로 변환할 때 사용 (리스트 -> 숫자(합), 리스트 -> Object)
